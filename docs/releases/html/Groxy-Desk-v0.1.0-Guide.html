Groxy Desk v0.1.0 — Walkthrough & Architecture Guide

Release Tier: PRE-1.0 Step 6 Native Desktop IDE | Default Bind: 127.0.0.1:9490 | Built With: Go CGO-Free WebView2 + GRAB v1.1.0 + Pure Grex JS v1.0.0

1. Plain-English Overview

Groxy Desk is the native Windows desktop IDE built for Step 6 of the GRAB Post-1.0 Ecosystem. Opening groxy-desk.exe launches an authenticated loopback host daemon (127.0.0.1:9490) and a native Microsoft Edge WebView2 desktop window—without requiring Electron or external cloud logins.

  • Zero Model-Switching Dropdowns: Groxy AI is your sole permanent assistant across the entire IDE. Its Adaptive Reasoning Router chooses instant execution for fast checks and gated planning with rollback safety for file changes.
  • Local Grisp Worker Control: Start, health-check, reload, inspect redacted logs for, and cleanly shut down up to 8 local grab.exe workers on 127.0.0.1:8765–8772.
  • Built-In grabman v1.0.0 Manager: Initialize projects, audit deployments with grabman doctor, and verify lockfiles with grabman solve --verify in one click.

3. Adaptive Reasoning Router & GROXY-SAFE-001 Rollback

  1. Fast Instant Path: Deterministic 22-rule SEO/A11Y/DOM/Link audits, grab check + canonical grab format checks, grabman doctor, and Grisp worker status checks execute immediately.
  2. Deep Gated Path: Code edits or layout fixes draft a step-by-step Plan, capture a pre-mutation SHA-256 Snapshot outside the workspace, and issue a single-use target-bound approval_token.
  3. 1-Click Snapshot Rollback: Every approved edit remains reversible to exact byte-for-byte original SHA-256 state in one click (or removes newly created files cleanly).

4. Pure Grex JS v1.0.0 Light & Dark Workbench

The entire browser workbench renders exclusively with the 20 semantic elements defined in grex.elements.json—guaranteeing divCount === 0, innerHTMLWriteCount === 0, zero eval()/new Function(), zero-FOUC theme loading, WCAG AA contrast (≥ 4.5:1) in both Light & Dark themes, and exact ADR-025c base-10 wire strings.
