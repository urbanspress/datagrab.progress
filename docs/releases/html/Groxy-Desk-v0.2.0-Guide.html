1. What's New in Groxy Desk v0.2.0 (Plain-English Overview)

Groxy Desk v0.2.0 connects the native desktop workbench to the full Post-1.0 ecosystem over authenticated loopback IPC—giving developers an all-in-one visual studio without leaving the IDE or modifying any frozen v1.x upstream repository.

  • Unified 13-Tool grab mcp Bridge: Execute Core GRAB v1.1.0 CLI tools (grab_check, grab_format, grab_inspect_routes, grab_inspect_schema, grab_scaffold), GrabLab CMS v1.0.1 draft/content tools (list_content_types, query_entries, create_entry_draft, update_entry_layout, list_media, list_menus), and Grex Theme Builder v1.0.0 endpoints (GET /api/design-system.md, POST /api/mcp/layout) under one permanent Groxy AI experience with zero model-switching dropdowns.
  • Live Split-Preview Workbench Canvas: Switch instantly between Code, Split, and Visual & Scorecard views connected to local Grisp workers (127.0.0.1:8765–8772) via GrexPreviewBridge (grex-preview-v1) across Base, Tablet (768px), and Mobile (375px) viewports.
  • 8 Style Packs × 5 Blueprints & 1-Click Ctrl+Z Undo: Generate WCAG AA Light & Dark zero-<div> layouts across all 40 Style Pack combinations enriched with GRAB-DESIGN-SYSTEM.md, SITE-CONTEXT.md, and grex.elements.json, dispatched with actor: "groxy-ai" and full applyAiLayout Ctrl+Z undo parity.
  • 22-Rule Scorecard & 🚀 “Let Groxy Boost This”: Inspect 4 equal-weight pillars (on_page_seo, content_a11y, performance_dom, linking_readiness — weight "25" each), review side-by-side before/after diffs with schema.org JSON-LD + semantic landmark fixes, and apply with Pre-Mutation SHA-256 Snapshot rollback.
