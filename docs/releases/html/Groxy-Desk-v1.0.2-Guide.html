What’s New in v1.0.2 (PATCH 1.0.x — Windows WebView2 Launch Fix)

Groxy Desk v1.0.2 is a critical 100% drop-in compatible patch release resolving a Windows startup crash that caused Groxy Desk to flash black and exit immediately:

  • WebView2 Handshake Serialization Fix (public/desk/workbench.js): Safely serializes the initial groxy-desk-ready handshake message via JSON.stringify instead of passing a bare JavaScript object, preventing go-webview2's internal TryGetWebMessageAsString() COM method from throwing E_INVALIDARG (0x80070057: “The parameter is incorrect”) and terminating the application process via os.Exit(1).
  • Window Class Registration Safety (cmd/groxy-desk/webview_windows.go): Tolerates ERROR_CLASS_ALREADY_EXISTS during repeated desktop window initializations without returning an error.
  • Updated Installer: Refreshes Groxy-Desk-Setup-1.0.2.exe, static binaries, SHA-256 signatures, and walkthrough PDF guide.
