1. Locked 100vh Desktop IDE Shell & Dark Obsidian / Clean Light Palettes

Groxy Desk v1.3.0 locks html, body, #desk-root to height: 100vh; max-height: 100vh; overflow: hidden; so outer viewports never scroll and every operational tool remains visible above the fold. Both the Dark Obsidian (#0f1115 / #181b20) and Clean Light (#f8fafc / #ffffff) palettes enforce WCAG AA contrast (≥ 4.5:1 text, ≥ 3.0:1 UI components), 1px solid var(--grex-border) hairline pane dividers, and compact 26px–28px semantic monospace form controls.

2. 32px Top IDE Menu & Command Bar + 48px Vertical Activity Icon Rail

The 32px top bar (#desk-header) provides an application menu bar (File, Edit, View, Database, Browser, Tools, Help), a centered Ctrl+K command search bar (#desk-command-search), active workspace badge, authenticated loopback badge (#desk-host-status-badge / #desk-connection-badge), and theme toggle (#desk-theme-toggle).

The 48px far-left vertical activity icon rail (#desk-activity-rail, role="tablist") renders crisp grab-ide-icons SVG vectors via Pure Grex JS Icon (createElementNS) for Explorer & Code (#desk-tab-code), Database Studio (#desk-tab-database), Browser & Radar (#desk-tab-browser), Grex Visual Builder (#desk-tab-grex), Server & Fleet (#desk-tab-fleet), plus bottom-anchored Settings (#desk-action-settings) and Shortcuts (#desk-action-shortcuts).

3. Locked Edge-to-Edge Studios & 28px Tabular Spreadsheet Grid

Database Studio (#desk-panel-database) pairs a 240px collapsible connection/schema tree with live object filtering (#desk-db-object-filter), multi-tab autocomplete SQL, a 28px-row-height sticky-header zebra-striped spreadsheet grid (.desk-grid-table, tabular-nums, exact ADR-025c wire strings), and a 280px GROXY-SAFE-001 inspector drawer (#desk-db-inspector). Browser & Radar (#desk-panel-browser) provides an edge-to-edge 50/50 split pane, and Code & Grex Studio (#desk-panel-code) combines workspace exploration, Coolify-density Server & Fleet pills, live Grex split-preview canvas, and Unified Groxy AI (zero model-switching dropdowns).

4. 24px Pinned Bottom IDE Status Bar

The 24px status bar (#desk-status-bar) surfaces five live indicators at all times: #desk-status-db (1-click database connection pill), #desk-status-ssh (pinned SHA256:... host fingerprint), #desk-status-safety (GROXY-SAFE-001 snapshot guard), #desk-status-grisp (active local worker pool), and #desk-status-adr025c (exact-wire runtime badge).
