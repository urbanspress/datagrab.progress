Groxy Desk v1.3.1

Faster remote database schema inspection

Install the patch

Download Groxy-Desk-Setup-1.3.1.exe and SHA256SUMS.txt from the same release. Compare the installer hash with the entry in the checksum file, then run the installer.

Open a remote schema

In Database Studio, open your saved PostgreSQL or MariaDB connection through its pinned SSH tunnel and refresh the schema. Expand Tables, Views, or Triggers in the schema tree.

What changed

Desk sends one catalog query and one query for exact table row counts, even when a database has dozens of tables. The inspection has a 20-second deadline. Views and triggers are listed according to the account's catalog visibility.

Row counts and database numeric values retain their exact decimal text. Database writes still require explicit approval and a pre-mutation snapshot.
