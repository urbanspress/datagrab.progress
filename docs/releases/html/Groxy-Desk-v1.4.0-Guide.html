Groxy Desk v1.4.0

True DbGate-Parity Connection Manager, Collapsible Rail & Full-Screen Spreadsheet Grid

Complete · All 4 Acceptance Gates Verified

1. Saved Connections & Tabbed Connection Window

The Database Studio left sidebar now shows a compact CONNECTIONS list at the top with a + New Connection button instead of raw form boxes. Click + to open the tabbed Connection dialog (General and SSH Tunnel tabs), then choose Save or Connect. Database and SSH passwords are encrypted on disk with AES-256-GCM (v1:...) and are never stored in browser storage.

Once saved, one click on any connection opens its pinned SSH tunnel and loads your database schema automatically. Use Edit, Disconnect, or Delete right on the connection card.

2. Collapsible Left Sidebar & Focused Schema Tree

Click the active left-rail icon (such as Database Studio or Code & Grex Studio) anytime to collapse or reopen the sidebar and give your data grid or code editor extra screen width. The lower 75% of the Database sidebar is dedicated to filtering and browsing Tables, Views, and Triggers with row-count badges; clicking any table loads its rows immediately.

3. Full-Screen Spreadsheet Grid & Dedicated Sub-Tabs

The center workspace uses a clean sub-tab bar (Data, Structure, SQL Query, ER Diagram, and Export & Diff) with a single-line action toolbar. Data opens by default as an edge-to-edge spreadsheet grid with sticky row numbers (1, 2, 3...), column names with data types, live per-column filter boxes, 28px rows, alternating row shading, and exact ADR-025c numbers.

4. Collapsed-by-Default Safety Inspector

The right-hand Row Inspector & Safety Gate stays tucked away by default so the spreadsheet grid fills the screen. Click or double-click any editable cell (or click Write SQL / Snapshot Guard) to slide the inspector open, review your change with a verified SHA-256 pre-mutation snapshot, and approve or roll back safely.
