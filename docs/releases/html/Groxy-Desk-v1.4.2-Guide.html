Groxy Desk v1.4.2

Console-free Windows launch and clearer workbench icons

Launch Groxy Desk

Run the Windows installer, then open Groxy Desk from the Start menu or the optional desktop shortcut. Groxy Desk opens directly in its native WebView2 window.

Browse a database

Open Database Studio from the activity rail. Use the plus button in Connections to add a saved connection, or select an existing profile. The connection status appears beside the Database Studio heading.

Expand Tables, Views, or Triggers in the sidebar. Use the search box to narrow the lists, then select a table to load its rows. The grid supports per-column filters and keeps row numbers and headers in view while you scroll.

Use the compact toolbar

Switch between Data, SQL, ER Diagram, and Export. The first Refresh button reloads table rows. The second Refresh button reloads the schema. Hover over either button to see which action it performs.

Open Database actions in the SQL view to find Structure, schema comparison, and snapshot controls. Open SQL tabs to add or switch query tabs.

Review edits before applying them

Click an editable cell or choose Save to open the Row Inspector & Safety Gate. Review the proposed change in the inspector. Applying a write still requires explicit approval and a pre-mutation snapshot. Decimal and integer values retain their exact precision.

Find commands and switch themes

Press Ctrl+K or select the magnifying glass on the activity rail to show command search. Press Esc to close it. Use Settings on the rail to switch between Light and Dark.
