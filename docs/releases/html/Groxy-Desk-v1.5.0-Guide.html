Groxy Desk v1.5.0

Unified Windows title bar and silent background tools

Install and open Groxy Desk

Run Groxy-Desk-Setup-1.5.0.exe. Open Groxy Desk from the Start menu or optional desktop shortcut. The native WebView2 window contains the menu bar, Command Search, theme switch, and Windows controls in one row.

Move, resize, and snap the window

Drag a blank space on the title bar to move the window. Drag to the edge of a display to snap, or double-click a blank space to maximize or restore. Resize from any outer edge or corner. Right-click a blank space or press Alt+Space to open the Windows system menu.

Find commands and switch themes

Click Command Search or press Ctrl+K. Enter database, browser, or code to switch studios. You can also open a workspace file by entering its path. Use the theme button beside the window controls to switch between Light and Dark.

Run workspace and database tools

GRAB checks, local workers, and helper programs run in the background. Read their output in the workbench. In Database Studio you can connect through the existing pinned SSH tunnel, inspect a schema, and review edits in the approval drawer. Writes still require approval and a pre-mutation snapshot.
