### Changes

- The Windows title bar combines the Groxy Desk logo, File through Help menus, Command Search, theme switch, and window controls. Drag blank space to move or snap the window. Right-click it for the native system menu.
- Desk starts its Windows background tools with console windows disabled. Tool output and diagnostics remain available in the workbench.
- The browser research pane stays below the title bar. Database values retain their exact precision, and writes still require approval and a snapshot.

Download the Inno Setup installer and Windows walkthrough from the release assets. Verify downloads with `SHA256SUMS.txt`.
